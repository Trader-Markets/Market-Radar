# Per-coin warning revalidation — build50, 29 October 2026

Customer screenshot showed a fresh overall-feed badge above hour-old historical alerts. That badge never established those individual warnings' current validity. Build50 adds separate per-coin revalidation to Live volume & big move.

Each saved warning retains its original range level, direction and detection time. While monitoring runs, every accepted incoming candle updates that coin's observed traded price. Status responses re-evaluate every warning using its own symbol's latest source timestamp. The two-second UI status check also ages out previously fresh observations. No extra broker-account requests or credentials are used.

HOLDING BREAKOUT NOW: a fresh source observation for that exact coin, within15seconds (at most1second future clock tolerance), current connection and market coverage, price strictly beyond the original range level, original warning at most10minutes old. This checks its original price reference ONLY. It does not re-confirm original volume, derivatives, fundamentals, entry distance, stop/target, profitability or continuous holding across an offline interval. It is not a new trade instruction or prediction.

INVALIDATED: a fresh observed price returns to/inside the original breakout range. That warning is retired, stored in bounded history, and cannot turn holding again after a rebound or restart. A new separately detected warning is needed. Invalidations update the durable local SQLite history or browser-only stored history through the same owner-scoped / serialised storage path; no messages are sent. Stored transient validation badges are discarded and recomputed after restart.

EXPIRED: the original warning is over10minutes old, regardless of an overall fresh feed badge. DATA STALE: that exact coin has no source price within15seconds; other coins receiving updates cannot substitute for it. UNVERIFIED: connection, feed coverage or required original reference unavailable. PAUSED: checks are not enabled/running. API failure immediately removes any holding display; a response delayed enough to age its quote cannot remain holding.

The main list shows current checks with bold state+coin, observed price, original level, symbol-specific source age and IST check time. Expired / invalidated warnings are moved into collapsed history. The original detection title is retained as historical evidence. A global LIVE badge is explicitly distinguished from per-coin freshness. Only fresh holding events younger than2minutes are eligible for the existing new-detection in-app toast; stale/invalidated records cannot issue it. Existing30minute detection dedup and all earlier scan cadences remain unchanged.
