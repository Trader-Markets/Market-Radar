Connect Telegram on your computer

You opened the hosted website. Your Telegram login and live news reader run in the Windows app on your computer.

  1. Download Breakout-Radar-Telegram-Posts.zip from our ChatGPT conversation and extract it.
  2. Close the old server window. Open Start Market Radar.cmd in the new folder. Let the first-time installation finish.
  3. Click below. Enter your API ID, API hash and phone number, then the code received in Telegram.
Open Telegram connection screen ↗

If the page cannot be reached, the new local server is not running. If it says “Not found”, you are running an older version.

After connecting, use the local Market Radar app → Setups → News. Incoming news appears there; this hosted website does not receive your local Telegram session or feed.

Enter codes and passwords only in the local connection screen. Keep the server window open and the computer awake.
